# huh: working notes

Living log of decisions, gotchas and what's left. Newest decisions at the bottom of each section.

## Layout
```
src/Huh.App          WinUI 3 tray app + bubble (assembly "Huh", namespace "Huh")
src/Huh.Core         UI-free: detection, dialog model, decoding, provenance, AI, privacy, actions
tools/Huh.TestHarness  raises error / non-error dialogs on demand (console, comctl32 v6 manifest)
tools/Huh.Probe      headless host for Core detection; JSONL log + harness scoring
tests/Huh.Tests      xUnit v3 (Microsoft.Testing.Platform runner)
```

## Build & run
- Build: `dotnet build Huh.slnx -c Debug -p:Platform=x64`
- Tests: `dotnet test --project tests/Huh.Tests`
- App:   `src/Huh.App/bin/x64/Debug/net10.0-windows10.0.26100.0/win-x64/Huh.exe`

## Decisions
- **.NET 10** (`net10.0-windows10.0.26100.0` for the app, `net10.0-windows` elsewhere). .NET 8 support ends 2026-11-10.
- **Unpackaged + self-contained Windows App SDK** (`WindowsPackageType=None`, `WindowsAppSDKSelfContained=true`) so the app
  can be launched/killed/screenshotted from the CLI. `EnableMsixTooling` stays on (needed for resources.pri). MSIX is optional (M6).
- Project renamed to **Huh.App**, but `AssemblyName=Huh` / `RootNamespace=Huh` to avoid a `Huh.App.App` namespace/type clash.
- Platforms: x64 + ARM64 (x86 dropped). Libraries are AnyCPU.
- Removed the template's `systemAIModels` capability: no NPU on the target machine (i7-1355U), so Windows AI APIs are unavailable.
- **Central package management** (`Directory.Packages.props`).
- **UI Automation via raw COM generated by CsWin32**, not FlaUI: FlaUI depends on tlbimp interop (built-in COM), which is
  disabled under trimming (Release publish trims). Raw COM also gives explicit control of UIA threading.
- **Tray icon via raw Shell_NotifyIcon** (H.NotifyIcon.WinUI is pre-release only).
- **Gemini default model `gemini-3.8-flash`, fallback `gemini-3.5-flash-lite`** (free tier per Google's pricing page, checked 2026-11-05).
  `gemini-2.5-flash` is deprecated (rerouted 2026-12-01). Free-tier data IS used by Google to improve products.
- **AI is opt-in**: nothing goes to Gemini until the user accepts on the first-run screen (which explains free-tier data use).
  Deterministic info (codes, source program, signature) works without AI.
- **Re-run as admin**: exe path only, never arguments. Blocked for unsigned binaries; override shows a red warning with the path + "unsigned".
- AI-chosen actions carry parameters that are validated (ms-settings from a fixed list, folders must exist locally, search query built by huh).
  Dialog text is untrusted input (prompt-injection vector).

## Gotchas
- `SupportedOSPlatformVersion` can't be set globally: `net10.0-windows` has TargetPlatformVersion 7.0 (NETSDK1135).
- .NET 10 SDK: `dotnet test` needs `"test": {"runner": "Microsoft.Testing.Platform"}` in global.json for xUnit v3; use `dotnet test --project ...`.
- TaskDialog needs a Common Controls v6 manifest dependency (harness has one).
- Mica/Acrylic render the inactive fallback in a never-activated window, so force `IsInputActive=true` (M2).
- `Window.Activate()` steals focus, so show the bubble with `SW_SHOWNOACTIVATE` (M2).
